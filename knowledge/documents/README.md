# Source documents

Run python ingest_documents.py from the repository root to download the seed documents listed in knowledge/sources.json into this folder.

The ingestion script also accepts documents you add yourself:
- PDF (.pdf), parsed page by page with PyMuPDF
- HTML (.html or .htm), cleaned and extracted with BeautifulSoup
- Text and Markdown (.txt or .md)

The checked-in sources.json records the source URL and reuse terms for each seed.
